Hephaistos 3D explores single-image 3D generation using **Sperid Labs' Idol** model and
Gaussian Splatting. The goal is to run the pipeline on my own NVIDIA infrastructure,
from weight installation to output export.

## My work

- Design the application, API contract and separation between web interface and GPU worker.
- Qualify the model on real hardware before building the user journey.
- Prepare a persistent job queue, cancellation and progress based on actual computation stages.
- Document memory constraints, architectural decisions and dependency licences.

## Project status

GPU feasibility is validated. **The inference engine is under development and the interface
is not usable yet.** Browser viewing and PLY export are planned. Model weights have separate
terms; the FLUX VAE includes a non-commercial restriction. My work is the integration,
not the creation of Idol.
